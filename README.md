# Hambugui Launcher

Hambugui 서버에 들어가는 Minecraft 런처입니다. 처음 실행하면 Microsoft 계정으로 로그인하고, 버튼 하나로 서버에 맞는 게임 파일과 모드를 받아 바로 접속합니다.

이 저장소는 **완성된 런처를 내려받는 곳**입니다.

## 내려받기

오른쪽 **Releases**에서 가장 위(최신) 버전을 열고, 내 컴퓨터에 맞는 파일 하나를 받으세요.

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows 10 / 11 (64비트) | `Hambugui-Launcher_<버전>_windows-x64-setup.exe` |
| Mac (Apple 칩: M1 이상, macOS 14 이상) | `Hambugui-Launcher_<버전>_macos-apple-silicon.dmg` |

- Intel 칩 Mac과 Linux는 지원하지 않습니다.
- `.app.zip`, `.json`, `SHA256SUMS` 파일은 런처가 자동 업데이트에 쓰는 파일입니다. 직접 받을 필요는 없습니다.

## 설치

이 런처는 코드 서명(운영체제 회사에 돈을 내고 받는 인증서)을 하지 않았습니다. 그래서 처음 열 때 경고가 나옵니다. 이 저장소의 Releases에서 받은 파일이라면 아래처럼 열면 됩니다.

### Windows

1. 받은 `setup.exe`를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보**를 누르고 **실행**을 누릅니다.
3. 설치가 끝나면 시작 메뉴에서 **Hambugui Launcher**를 엽니다.

### Mac

1. 받은 `.dmg`를 열고, **Hambugui Launcher**를 **응용 프로그램** 폴더로 끌어 놓습니다.
2. 응용 프로그램 폴더에서 런처를 엽니다. "확인되지 않은 개발자" 경고가 뜨면 **완료**를 누릅니다.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서, 아래쪽의 **그래도 열기**를 누르고 다시 엽니다.

한 번 열고 나면 다음부터는 경고 없이 열립니다.

## 업데이트

따로 받을 필요가 없습니다. 런처가 시작할 때 이 저장소에서 새 버전을 확인하고, 미리 받아 둔 뒤 서명이 맞는지 검사합니다. 준비가 끝나면 플레이 버튼이 **업데이트**로 바뀌고, 누르면 적용됩니다. 서명이 맞지 않는 파일은 적용하지 않습니다.

## 로그인

로그인은 Microsoft 로그인 창에서 합니다. 런처는 비밀번호를 보지 않습니다. 로그인 정보는 Windows에서는 자격 증명 관리자에, Mac에서는 내 계정만 읽을 수 있는 파일에 저장됩니다.

## 받은 파일이 맞는지 확인하기 (선택)

같은 Release에 있는 `SHA256SUMS`와 비교하면, 받은 파일이 올린 파일과 똑같은지 확인할 수 있습니다.

- Windows (PowerShell): `Get-FileHash .\Hambugui-Launcher_<버전>_windows-x64-setup.exe -Algorithm SHA256`
- Mac (터미널): `shasum -a 256 Hambugui-Launcher_<버전>_macos-apple-silicon.dmg`

출력된 값이 `SHA256SUMS`의 같은 파일 줄과 같으면 됩니다.

## 문제가 생기면

- 런처의 **설정 → 문제 해결**에서 게임 로그를 올리거나(**mclo.gs에 올리기…**) 지원 파일을 만들 수 있습니다(**지원 파일 내보내기**). 비밀번호와 토큰은 자동으로 가려집니다.
- 화면에 나온 오류 코드(예: `코드 auth.oauth.callback_timeout`)를 함께 알려 주세요.
